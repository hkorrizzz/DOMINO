Консольная пошаговая игра в классическое домино для двух игроков (с++, 2023)

- Работа со структурами 
- Массивы и индексы
- Функции с параметрами
- Генерация случайных чисел (rand/srand)
- Указатели и ссылки
- Вложенные циклы
- Игровая логика (пошагово, проверка ходов)
- Обработка ситуаций (победа, ничья, пропуск хода)
